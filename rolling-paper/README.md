# 마음 한 장

Node.js 20 이상에서 추가 설치 없이 실행할 수 있는 온라인 롤링페이퍼입니다.

```powershell
node server.js
```

서버를 실행한 컴퓨터에서는 [localhost:3000](http://localhost:3000)을 엽니다. 같은 와이파이에 연결된 친구들은 서버 컴퓨터의 IPv4 주소로 접속하면 됩니다. Windows에서는 `ipconfig`로 확인할 수 있습니다. 예를 들어 서버 주소가 `192.168.0.12`이면 `http://192.168.0.12:3000`을 공유하세요. 접속이 막히면 Windows 방화벽에서 해당 사설 네트워크의 Node.js 인바운드 연결을 허용하세요.

- 같은 주소를 연 사람들은 롤링페이퍼 한 개를 함께 사용합니다. 변경 사항은 약 2초 안에 다른 접속자 화면에 반영됩니다.
- 제목과 받는 사람은 전체 페이지에 적용됩니다. 배치와 배경은 페이지마다 설정할 수 있습니다.
- 페이지당 카드 40장, 롤링페이퍼당 페이지 12개까지 추가할 수 있습니다. **PNG 저장**은 열어 둔 페이지를 저장합니다.
- 데이터는 서버 폴더의 `board.json`에 저장됩니다. 서버를 다시 시작해도 이어서 쓸 수 있습니다.
- 접속한 사람 모두가 꾸미기와 페이지 관리를 할 수 있으므로 신뢰하는 사람들과 주소를 공유하세요.
